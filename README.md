# ST Theme Painter · 改色盒子

一个 SillyTavern 插件，基于背景图自动提取主色调并结合 AI 审美搭配，生成匹配该图片的完整「双色盒子」界面主题。

## v2.0 特性

- **多种图片来源**：支持粘贴图片直链、**一键读取酒馆当前背景图**、以及**本地选择图片**（自动 WebP/JPEG 压缩嵌入主题）。
- **三种配色引擎按需切换**：
  - **纯本地（免费秒出）**：默认模式，纯前端 Canvas 像素采样 + 色彩学算法生成高可读性配色，零 API 消耗、0 延迟。
  - **图片注解视觉（省主 API）**：直接复用酒馆「图片注解（Image Captioning → Multimodal）」里配置的低价识图模型，看图一步直出配色 JSON，不消耗昂贵的主聊天 API。
  - **当前主 API**：把本地采样的精确色值发给当前主 API 进行搭配与起名。
- **保留个人布局习惯**：保存主题时继承你当前的头像样式、字号、聊天宽度等设置，不再覆盖原有习惯。
- **对比度自检与色块微调**：内置 WCAG 文字对比度检查；生成后点击色卡任意色块即可直接微调颜色，并实时复检。
- **一键撤销与完整导出**：应用新主题后可一键撤销恢复原主题；支持导出可直接导入酒馆的完整主题 JSON，也支持查看/复制 CSS。

## 使用方法

1. 在 SillyTavern 用户设置页面（主题选择器下方）展开 **Theme Painter · 改色盒子** 面板。
2. 选择图片来源：粘贴直链后点载入、点「当前背景」读取酒馆当前背景，或点文件夹图标选择本地图片。
3. 可按需选择界面明暗倾向（自动 / 浅色 / 深色）以及是否勾选「视觉氛围增强」。
4. 点击「分析配色」，生成后可点击色块微调颜色。
5. 确认主题名称后点击「应用并保存」；若效果不满意，可点击「撤销」一键还原。
