# ST Theme Painter · 改色盒子

一个 SillyTavern 插件，根据背景图自动提取主色调并生成匹配该图片的完整「双色盒子」界面配色主题。支持纯本地离线秒出，也支持调用低价视觉模型或主聊天 API 进行审美搭配。

## 主要特性

- **三种图片来源**：
  - **图片直链**：粘贴外部图片 URL 后点击「载入」。
  - **当前背景**：一键读取酒馆当前正在显示的背景图（无需找链接，无跨域问题）。
  - **本地选图**：直接从电脑或手机相册选图，前端会自动缩放并压缩为 WebP/JPEG 后以 Base64 嵌入主题，导出分享时自带背景图、不依赖图床。
- **三种配色引擎（按需切换）**：
  - **纯本地（免费秒出 · 默认推荐）**：完全不调用任何 API。前端使用 Canvas 对图片像素采样，结合 HSL 色彩学、边缘纹理复杂度检测（自动给出克制的 `0～4` 模糊度）与 WCAG 对比度约束，0 延迟直接生成高可读性配色方案。
  - **图片注解视觉（省主 API）**：直接复用酒馆内置「图片说明 / 圖片註解（Image Captioning）」扩展中配置的多模态模型，让低价识图模型看图一步直出配色 JSON，**完全不消耗昂贵的主聊天 API**。
  - **当前主 API**：先在本地用 Canvas 提取精确色值，再交由酒馆当前连接的主聊天模型进行审美搭配与主题命名（主 API 为纯文本模型也可正常使用）。
- **先预览，满意再保存**：
  - 点击 **「预览」** 可直接在当前页面实时查看效果，不写主题文件、不修改设置；预览期间点击上方色卡任意色块可实时调色。
  - 不满意可点击 **「还原」** 一键退回原主题；满意后再点击 **「保存」**。
- **保留个人布局习惯**：保存主题时自动继承你当前的头像样式、字号、聊天宽度等设置，不会覆盖原有偏好。
- **完整导出**：支持一键导出可直接导入 SillyTavern 的完整主题 JSON 文件，也支持查看与复制 CSS。

## 使用方法

1. 在 SillyTavern **用户设置** 页面（主题选择器下方）展开 **Theme Painter · 改色盒子** 面板。
2. 选择图片来源：粘贴直链后点「载入」、点「当前背景」，或点「本地选图」。
3. 选择配色引擎（默认「纯本地」即可直接用）与界面明暗倾向（自动判断 / 浅色界面 / 深色界面）。
4. 点击 **「分析配色」**，生成后可点击色卡中的任意色块微调颜色。
5. 点击 **「预览」** 查看全界面效果，确认满意后填写主题名并点击 **「保存」**（不满意点「还原」）。

## 「图片注解视觉」引擎配置说明（可选）

仅当你希望使用 **「引擎：图片注解视觉（省主 API）」** 时才需要配置以下步骤；使用默认的「纯本地」模式可完全跳过。

1. 打开酒馆顶栏的 **扩展（Extensions）** 页面，找到 **Image Captioning**（简体中文界面通常显示为 **图片说明 / 图片描述**，繁体中文界面显示为 **圖片註解**）。
2. 将 **Source / 来源** 设为 **Multimodal / 多模态**。
3. 在 **API** 中选择支持识图的接口（如 Google、Anthropic、OpenAI 或自定义 OpenAI 兼容反代）。
4. 在 **模型（Model）** 中选择一个**支持识图**的模型（例如低价多模态模型 `gemini-2.5-flash`、`gpt-4o-mini` 等）：
   - 如果 API 选的是 **自定义（兼容 OpenAI）** 且模型选了 `[Custom model]`，务必在下方的 **Model Id** 输入框里填上支持识图的模型名；留空或填纯文本模型会导致接口返回 `500` 报错。
5. 配置完成后，回到改色盒子面板将引擎切到 **「图片注解视觉（省主 API）」** 即可使用。
